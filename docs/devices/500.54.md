## Notes

### Factory Reset and Pairing

1. Starting from Power On state
2. Repeated five times switching power Off an On again.
  - Off for 2-3 seconds
  - On for 1-2 seconds
3. After successful factory resetting
  - the bulb "breathes" or flashes
    and powers up to 100% brightness
  - starts discovery mode
4. The device is in discovery mode for 3 minutes

If there is no confirmation flashing in step 3 please wait a moment and start over.

### Variants

Different light variants have identical ZigBee modelID `RGBW light `.
In consequence those devices can show up inaccurate.
