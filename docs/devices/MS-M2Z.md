## Notes

MoveSmart MS-M2Z is a Zigbee 1 gang switch module with power monitoring.

Features:

- Remote ON/OFF control.
- Real-time power monitoring.
- Current measurement.
- Voltage measurement.
- Energy consumption monitoring.
- Switch type configuration.
- Power outage memory configuration.
