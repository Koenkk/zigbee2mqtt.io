Exposes

Spray (enum)

One action triggers one spray. This control has no persistent state.. Value will not be published in the state. It's not possible to read (/get) this value. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"spray": "VALUE"}. The possible values are: SPRAY.

Mode (enum)

Current mode set by the physical selector. Value can be found in the published state on the mode property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"mode": ""}. It's not possible to write (/set) this value. The possible values are: OFF, AUTO, SCHEDULE, PROGRAMMABLE.

SCHEDULE (text)

Built-in schedule; no editing required.. Value can be found in the published state on the schedule_info property. It's not possible to read (/get) or write (/set) this value.

Battery voltage (numeric)

Battery voltage. Value can be found in the published state on the battery_v property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"battery_v": ""}. It's not possible to write (/set) this value. The unit of this value is V.

Battery level (numeric)

Battery level. Value can be found in the published state on the battery property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"battery": ""}. It's not possible to write (/set) this value. The minimal value is 0 and the maximum value is 100. The unit of this value is %.

Spray duration (numeric)

Shared by OFF, AUTO, SCHEDULE and PROGRAMMABLE; persists when switching modes.. Value can be found in the published state on the spray_duration_ms property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"spray_duration_ms": ""}. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"spray_duration_ms": VALUE}. The minimal value is 300 and the maximum value is 1000. The unit of this value is ms.

AUTO: interval (numeric)

Spray interval in AUTO mode. Value can be found in the published state on the auto_interval_min property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"auto_interval_min": ""}. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"auto_interval_min": VALUE}. The minimal value is 1 and the maximum value is 1440. The unit of this value is min.

PROGRAM — Monday: enabled (binary)

Enable this weekday program. Value can be found in the published state on the program_mon_enabled property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"program_mon_enabled": ""}. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"program_mon_enabled": "VALUE"}. If value equals ON pROGRAM — Monday: enabled is ON, if OFF OFF.

PROGRAM — Monday: start (text)

HH:MM. Value can be found in the published state on the program_mon_start property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"program_mon_start": ""}. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"program_mon_start": "VALUE"}.
